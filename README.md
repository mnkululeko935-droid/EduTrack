# EduTrack Learner Support (Demo)

Founded by M&M Tech Innovation.

A South African school early-support platform for Grades 8 to 12, with School, Learner and Guardian, and District portals.

**This is a demonstration. All data is fictional. It is not a live system and is not approved by or integrated with any education department.**

## Status
- Landing page with 3D grade books and portal previews: done
- Teacher dashboard (traffic-light indicators): next
- Learner results and calculator: planned
- Back end (FastAPI), database (PostgreSQL), authentication: planned

## Run locally
Open `index.html` in a browser.
